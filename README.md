# To-Do List

This is a simple to-do list web app built with HTML, CSS, and JavaScript. It lets you add tasks, display them on the page, and remove them when they are no longer needed.

The main goal of this project is to practice basic front-end development and JavaScript events in a simple and practical way.

## Features

- Add new tasks
- Remove tasks with a delete button
- Prevent empty tasks from being added
- Simple and clean user interface

## Files

- index.html - structure of the page
- style.css - styling for the layout and buttons
- java.js - JavaScript logic for adding and deleting tasks

## How to use

1. Open the project folder in your browser.
2. Type a task in the input box.
3. Click the Add button or press Enter.
4. Use the Delete button to remove any task.

This project was created as a small practice project to improve web development skills and understand how interactive pages work.
